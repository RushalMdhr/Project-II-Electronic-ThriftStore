______________________________________________ Installation ___________________

        ⚠️⚠️    WARNING !!  ⚠️⚠️ 
to install the backend lib you just need to install 
...yourfolders/PROJECT-II/> npm i ...
without moving inside backend

But to install the frontend lib you must change directory 
cd ./frontend/. > npm i
to install the lib
